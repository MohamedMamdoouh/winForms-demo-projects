# WinForms Demo Projects

This repository contains a set of Windows Forms demo applications built with C#. Each project is designed to demonstrate core WinForms concepts such as form controls, event handling, layout, and application logic.

## Projects

- **Pizza Order**
  - A simple ordering interface for selecting pizza options and calculating order details.
  - Demonstrates form controls, input validation, and dynamic UI updates.

- **Pool Club**
  - A demo form that showcases control interaction and layout management in a club-style application.
  - Includes custom controls and event-driven behavior.

- **Traffic Lights**
  - Simulates a traffic light system using buttons, labels, and timed state changes.
  - Useful for learning how to manage timers and UI state in WinForms.

- **XO Game**
  - A classic Tic-Tac-Toe game implemented as a WinForms application.
  - Shows game state tracking, button grid interactions, and win/draw detection logic.

## Getting Started

1. Open the solution file in Visual Studio.
2. Restore any NuGet packages if prompted.
3. Set the desired project as the startup project.
4. Build and run the application.

## Notes

- The repository is intended for learning and experimentation with Windows Forms.
- The `.gitignore` file is configured to exclude build artifacts, IDE settings, and temporary files.
