# XO Game - Tic-Tac-Toe Game Implementation

Simple yet complete implementation of the classic tic-tac-toe (XO) game with game logic, win conditions, and player management.

## 📁 System Overview

Complete game implementation including:

- Game board management
- Turn-based gameplay
- Win/draw detection
- Game history tracking
- UI and user interaction

## 🎯 Features

### Game Logic

- 3x3 game board
- Turn management
- Move validation
- Win condition checking (rows, columns, diagonals)
- Draw detection
- Undo functionality

### Game Flow

- Initialization
- Move input and validation
- Board update
- Win/draw check
- Turn switching
- Game end

### UI

- Board display
- Current player indicator
- Move input
- Game status
- Reset option
- Game history

## 🛠️ Technologies

- C#
- Windows Forms
